Используйте код с осторожностью.
Вывод: Обратите внимание на таймстампы. В секунду 39.363 - 39.364 ваша программа обработала 5 пакетов подряд практически в одну и ту же миллисекунду.
Это классическое поведение накопления очереди в TCP-буфере ОС. Пока ваша программа ждала данные, операционная система (или сетевая карта) приняла пачку пакетов от Binance, склеила их в буфер сокета, а когда ваш цикл чтения проснулся, он выгреб их из памяти один за другим без пауз на сеть.
Для симулятора и бэктеста это нормально, но в реальном HFT это означает, что пакет 102429070036 пролежал в буфере лишние миллисекунды, ожидая, пока до него дойдет очередь чтения.
